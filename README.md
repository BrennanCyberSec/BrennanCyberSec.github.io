# BrennanCyberSec.github.io

Professional cybersecurity portfolio site for Brennan Vigna, focused on blue team operations, detection engineering, SOC workflows, and hands-on lab documentation.

## Live Site

- https://brennancybersec.github.io/

## Repository Structure

- `index.html` - Homepage and portfolio overview
- `labs.html` - Security labs and filtering interface
- `tools.html` - Tool stack and technologies
- `resume.html` - Resume page and downloadable PDF
- `contact.html` - Contact and networking links
- `assets/css/style.css` - Shared site styles
- `assets/js/nav.js` - Mobile navigation behavior
- `assets/js/filter.js` - Labs filtering behavior
- `assets/images/` - Site image assets (including favicon)
- `assets/gifs/` - GIF assets for labs/projects
- `assets/resume/` - Resume PDF assets

## Local Development

This is a static site. No build step is required.

1. Clone the repository.
2. Open the folder in VS Code.
3. Use Live Server (or open `index.html` directly) to preview changes.

## Content Maintenance

- Add new labs in `labs.html` using consistent `data-category` values.
- Keep footer and navigation links synchronized across all pages.
- Store all JavaScript under `assets/js/` and all media under `assets/images/` or `assets/gifs/`.
